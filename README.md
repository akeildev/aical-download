# Aical for Mac (preview)

**[Download Aical.dmg](https://github.com/akeildev/aical-download/releases/latest/download/Aical.dmg)**

- Works on Macs with Apple Silicon (M1 or newer), macOS 13 or newer.
- Open the downloaded file and drag **Aical** into **Applications**.
- Open Aical from Applications and follow the setup steps.

This is an early preview shared with invited people. It does not update by itself; a new version means a new download from this page.
